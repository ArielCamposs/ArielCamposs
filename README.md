## 👋 Sobre mí

Soy **Ariel Campos**, Analista Programador Computacional egresado de **Duoc UC**, desde **La Ligua, Chile** 🇨🇱.
Construyo aplicaciones web, móviles y de escritorio que resuelven procesos reales: **tiendas online con panel de administración, sistemas de inventario y bodega, reservas y apps para comunidades**.

- 🔭 Hoy trabajo principalmente con **Next.js, React, TypeScript, Astro, Supabase y Tailwind CSS**.
- 📱 También desarrollo apps móviles con **Expo / React Native** y de escritorio con **Electron**.
- 🚀 Publico mis proyectos en **Vercel**. Muchos tienen demo en vivo, ¡pruébalos abajo!
- 💬 ¿Tienes un proyecto en mente? Escríbeme a **arielcampos.dev@gmail.com**.
